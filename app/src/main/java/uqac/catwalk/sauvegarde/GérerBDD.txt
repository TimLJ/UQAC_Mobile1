Copie de la réponse de copilot sur comment faire pour initialiser et modifier la BDD via l'IDE

    1. Pour l'initialisation (remplir la BDD la toute première fois)

C'est la méthode pour s'assurer que lorsque l'application est lancée pour la première fois sur un
nouvel appareil, la base de données contient déjà des données de départ (par exemple, votre liste
de 36 chats).

La méthode standard consiste à utiliser une fonction de "callback" que Room fournit.
Vous donnez à Room une série d'instructions à exécuter uniquement au moment où il crée la base de
données pour la première fois. Dans ce code, vous insérez toutes les données initiales dont votre
application a besoin pour fonctionner. C'est propre, automatique et reproductible.


    2. Pour la modification et le débogage (consulter et changer les données pendant que vous codez)

C'est probablement ce que vous avez en tête. Pendant que votre application tourne en mode débogage
sur un émulateur ou un appareil, Android Studio vous donne un outil puissant appelé l'inspecteur de
base de données (Database Inspector).

Avec cet inspecteur, vous pouvez :
•Voir en direct le contenu de vos tables (Cat, Item, etc.).
•Modifier les valeurs directement dans les cellules, comme dans un tableur.
•Exécuter des requêtes SQL à la volée pour insérer, mettre à jour ou supprimer des lignes, vous
permettant de tester rapidement des scénarios sans avoir à écrire de code dans l'application.


En résumé :
•Pour les données initiales : Vous écrivez du code une seule fois qui peuple la base de données
lors de sa création sur l'appareil.

•Pour tester et modifier pendant le développement : Vous utilisez l'inspecteur de base de données
d'Android Studio pour interagir en temps réel avec la base de données qui s'exécute dans votre
application de débogage.


Fragment de code exemple pour modifier la BDD. A creuser
// Dans une Activity, un Fragment ou un ViewModel

// 1. Obtenez une instance de la base de données
val database = AppDatabase.getDatabase(applicationContext)

// 2. Accédez au DAO
val catDao = database.CatDao()

// 3. Lancez une coroutine pour effectuer l'opération de base de données
// Si vous êtes dans un ViewModel, utilisez viewModelScope.launch
// Si vous êtes dans une Activity/Fragment, utilisez lifecycleScope.launch
lifecycleScope.launch {
    // Créez l'objet que vous voulez insérer
    val newCat = Cat(
        name = "Misty",
        happiness = 80,
        cleanliness = 95,
        affection = 0.7f,
        achievementId = null // Pas encore de succès
    )

    // 4. Appelez la méthode du DAO
    catDao.insert(newCat)
}
